App Connect for Portable Web Spaces v0.1

App Connect is a CHAPI/VCALM profile by which a web application connects to a Portable Web Spaces (PWS)-backed wallet in a single exchange, obtaining a per-user application identity and delegated storage capabilities. It defines the AppConnectQuery request, the app-key credential, the invocation-target descriptor vocabulary with per-class allowed actions, the signed response presentation, and the fail-closed processing rules.

This is an experimental specification and is undergoing regular revisions.
